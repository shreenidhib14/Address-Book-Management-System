# Address Book Management System Using C

## Project Overview

This project implements a menu-driven Address Book Management System in C to manage contact information efficiently. It allows users to create, view, search, modify, and delete contact records. The application uses C programming concepts such as structures, pointers, functions, and file handling to organize and manage contact data.

## Features

- Add new contacts.
- Search and view contact information.
- Update existing contact details.
- Delete unwanted contacts.
- Display the list of saved contacts.
- Save contact information for future use.
- Menu-driven user interface.

## Technologies Used

- Programming Language: C
- Concepts: Structures, Pointers, Arrays, File Handling, Strings, Functions, Dynamic Memory Allocation, Modular Programming.

## Key Learnings

- Understanding contact management using C programming.
- Implementing CRUD operations for managing contact records.
- Working with structures, pointers, and functions.
- Using file handling to store and retrieve contact information.
- Improving problem-solving and modular programming skills.
